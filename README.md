# المرصد الإخباري العالمي

منصة تجمع تلقائيًا كل خبر يتعلق بـ **السعودية، الخليج، الحرب، التداعيات** من نحو 40 مصدرًا إخباريًا عالميًا (مصادر تقرير "قاعدة بيانات أقوى المصادر الإخبارية")، ويُعرض كل خبر **بلغته الأصلية** مع رابطه.

## البنية
- **fetch_news.py** — يجلب خلاصات RSS كل 30 دقيقة، يفلتر العناوين بكلمات مفتاحية بـ14 لغة، ويدخل المطابق في Supabase. المصادر التي لا توفر RSS مباشرًا (رويترز، بلومبرغ، FT، أسوشيتد برس...) تُجلب عبر Google News RSS كبديل.
- **sources.json** — قائمة المصادر وروابط الخلاصات؛ يمكن إضافة أو حذف أي مصدر بتعديل هذا الملف فقط.
- **index.html** — الواجهة (GitHub Pages): إحصاءات، تصفية حسب الفئة والمصدر واللغة، وبحث في العناوين.
- **schema.sql** — جدول قاعدة البيانات وسياسات الحماية.

## خطوات التشغيل

### 1. Supabase
1. أنشئي مشروعًا جديدًا (أو استخدمي المشروع الحالي).
2. افتحي SQL Editor وشغّلي محتوى `schema.sql`.

### 2. GitHub
1. أنشئي مستودعًا جديدًا وارفعي هذه الملفات إليه.
2. من Settings → Secrets and variables → Actions أضيفي سرّين:
   - `SUPABASE_URL` — رابط المشروع (https://xxxx.supabase.co)
   - `SUPABASE_SERVICE_KEY` — مفتاح **service_role** (من Settings → API في Supabase)
3. من تبويب Actions شغّلي workflow "Fetch global news" يدويًا أول مرة (Run workflow) للتأكد من عمله، وبعدها يعمل تلقائيًا كل 30 دقيقة.

### 3. الواجهة
1. في `index.html` ضعي قيمتي `SUPABASE_URL` و`SUPABASE_ANON_KEY` (مفتاح anon **العام** فقط — لا تضعي service_role هنا أبدًا).
2. فعّلي GitHub Pages من Settings → Pages (النشر من الفرع الرئيسي).

## ملاحظات
- التكرار يُمنع تلقائيًا عبر قيد فريد على رابط الخبر.
- بعض الخلاصات قد تتعطل مستقبلًا؛ السكربت يتجاهل الخلاصة المتعطلة ويكمل، ويظهر ذلك في سجل Actions.
- لتعديل الكلمات المفتاحية (إضافة "أوبك+"، اسم مدينة، إلخ) عدّلي القاموس `KEYWORDS` في `fetch_news.py`.
- فئات التصنيف الأربع: `saudi` السعودية، `gulf` الخليج، `war` الحرب، `repercussions` التداعيات؛ الخبر الواحد قد يحمل أكثر من فئة.
